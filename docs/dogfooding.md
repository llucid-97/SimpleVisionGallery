# Next week on Pali

Open **Simple Vision Gallery** and grant Photos access. This is a separate app, so its settings and hidden albums start fresh. It uses the same Photos library as Simple Vision Tools.

Try these during normal use:

- Select several items in the grid, open the selection menu and choose Share. In a slideshow, use the top-bar More menu, then Share. These actions prepare original media files for the system share sheet; generated depth scenes are not exported.

- Move a photo, then check the original album in Photos. The same item should be gone; a separate, identical-looking copy stays separate.
- Rename an album by pinching and holding its card. Try a small typo in album search and in the move picker. The three latest move destinations should appear first.
- Swipe forward and back, then move the current photo. The default buffer is five ahead and two behind; both sizes can be changed in Settings.
- Open two spatial slideshows. Both should prepare nearby photos. With many windows, the shared buffer gets smaller to limit preparation work.
- Use Select All or long pinch the first and last items of a range. Normal removal sends the whole selection to Recycle Bin immediately. Inside Recycle Bin, Delete Permanently uses one batch request to Photos.
- Compare portrait, square, and landscape video thumbnails. Their duration badges should stay in the same corner.

The Simulator checks real Photos membership, navigation, cache behavior, controls, and visible native media. This week’s headset check is for generated depth, stereo video, gaze targeting, and how quickly spatial scenes become ready during real browsing.

Permanent spatial-scene storage remains deferred. Removing Gallery does not undo album changes made in Photos.
